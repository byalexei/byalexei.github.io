# Сайт-визитка

Обычный статический сайт: HTML + CSS + JavaScript, без сборки и без сервера.
Открывается двойным кликом по `index.html`.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.js` | **Весь текст сайта.** Правишь только его. |
| `index.html` | Скелет страницы. Трогать почти не нужно. |
| `styles.css` | Оформление: цвета, отступы, шрифты. |
| `script.js` | Расставляет тексты по местам, переключает язык. |
| `files/` | PDF-версии резюме, которые отдаёт кнопка «Скачать резюме». |

## Как менять содержимое

1. Открой `data.js` в любом текстовом редакторе (подойдёт Блокнот, лучше — VS Code).
2. Меняй текст **внутри кавычек**. Кавычки, запятые и скобки не трогай.
3. Сохрани и обнови страницу в браузере (`F5`).

Русская версия — в блоке `ru`, английская — в блоке `en`.
Наборы полей должны совпадать, иначе при переключении языка что-то пропадёт.

Если нужен апостроф внутри текста в одинарных кавычках — экранируй его: `'It\'s fine'`.
Проще: используй для таких строк двойные кавычки `"It's fine"`.

### Убрать блок

Оставь пустую строку `''` — блок не покажется (работает для `status`, `location`, `note`, `price`).
Чтобы убрать пункт из списка (услугу, место работы, навык) — удали его вместе с запятой.

### Поменять цвет

В `data.js` строки `accent` и `accent2` — два акцентных цвета.
На их паре построены все градиенты: заголовки, цифры, кнопки, кольцо вокруг фото,
линия времени в блоке опыта. Меняешь пару — перекрашивается весь сайт.

Оба цвета должны быть достаточно тёмными: на них лежит белый текст кнопки.

### Поменять фотографию

Замени `photo.jpg` в папке с сайтом. Требования: квадратная, лицо по центру,
около 800×800 пикселей, до 150 КБ. Файла нет — покажется кружок с инициалами.

Исходник `IMG_0107_cut.jpg` лежит рядом на случай, если понадобится перекадрировать.
Выкладывать его в интернет не нужно.

## Резюме в PDF

Кнопка «Скачать резюме» отдаёт готовый файл из папки `files`:
`cv-ru.pdf` для русской версии, `cv-en.pdf` для английской.
Это копии полных резюме из `Desktop 1\CV`. **Обновил резюме — замени эти два файла**,
имена оставь прежними.

Если очистить поле `cvFile` в `data.js`, кнопка вместо файла откроет печать браузера
(там в поле «Принтер» есть «Сохранить как PDF») — вёрстка для печати уже настроена.

## Сайт в интернете

Адрес: **https://byalexei.github.io**

Хостинг — GitHub Pages, бесплатно. Файлы лежат в репозитории
`github.com/byalexei/byalexei.github.io`; всё, что попадает в ветку `main`,
через минуту-две появляется на сайте.

### Как обновить сайт

1. Правишь файлы (обычно только `data.js`).
2. Отправляешь изменения:

```bash
git add -A
git commit -m "Что поменял"
git push
```

Или просто просишь Claude Code: «отправь изменения на сайт».

Свой домен (`имя.ru`) при желании подключается к этому же адресу —
в настройках репозитория, раздел Pages → Custom domain.

## Локальный просмотр

Двойного клика по `index.html` достаточно.
Если нужен «настоящий» адрес (например, чтобы открыть сайт с телефона в той же сети),
в папке лежит `.claude/launch.json` — он запускает локальный сервер на `http://localhost:8765`.
