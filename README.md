# Сайт-визитка — byalexei.github.io

Статический сайт без сервера и фреймворков. Две языковые версии:
английская в корне (`/`), русская в `/ru/`.

## Как устроено

Весь текст лежит в одном файле — `data.js`. Из него скрипт сборки
генерирует готовые страницы с текстом внутри: так превью ссылок в
мессенджерах и поисковики видят содержимое без выполнения JavaScript.

| Файл | Что это |
|---|---|
| `data.js` | **Весь текст сайта** на двух языках. Единственное, что нужно править. |
| `build.js` | Сборка: `node build.js` → `index.html`, `ru/index.html`, `sitemap.xml`, `robots.txt`. |
| `styles.css` | Оформление. |
| `script.js` | Мелкие удобства в браузере: выбор языка, меню «Скачать резюме», анимации. |
| `photo.jpg` | Фотография (760×760). |
| `files/` | PDF-версии резюме. |
| `og-image-*.jpg`, `favicon*`, `apple-touch-icon.png` | Картинки превью и иконки. Генерируются скриптом `tools/og-image.py`. |
| `index.html`, `ru/index.html`, `sitemap.xml`, `robots.txt` | **Генерируются сборкой.** Руками не править — перезапишется. |

## Как обновить сайт

1. Правишь текст в `data.js` (русский — блок `ru`, английский — `en`).
2. Собираешь страницы:

```bash
node build.js
```

3. Отправляешь на сайт:

```bash
git add -A
git commit -m "Что поменял"
git push
```

Через минуту-две изменения появятся на https://byalexei.github.io.
Или просто просишь Claude Code: «обнови сайт».

### Если поменялось имя, должность или фото

Перегенерируй картинки превью и иконки, потом собери сайт:

```bash
python tools/og-image.py
node build.js
```

Нужен Python с библиотекой Pillow (`pip install pillow`).

### Поменять фотографию

Замени `photo.jpg`: квадратная, лицо по центру, около 800×800, до 150 КБ.
После замены — перегенерировать картинки превью (см. выше).

### Поменять цвет

`accent` и `accent2` в `data.js`. После правки — `python tools/og-image.py` и `node build.js`.

### Добавить рекомендации

В `data.js` в блоке `testimonials.items` (в обоих языках):

```js
{ text: 'Цитата…', name: 'Имя Фамилия', title: 'Должность, компания' }
```

Секция появится сама, как только в списке есть хотя бы один элемент.

## Языковые версии

Английская версия открывается по умолчанию. Если у посетителя браузер на русском
и он ещё не выбирал язык, его автоматически переводит на `/ru/`.
Явный выбор через переключатель запоминается в браузере.

Чтобы сделать русскую версию основной, в `build.js` поменяй местами папки
в `PAGES` и в `script.js` — условие автоперехода.

## Локальный просмотр

Двойной клик по `index.html`. Для проверки с телефона в той же сети —
`.claude/launch.json` запускает сервер на `http://localhost:8765`.

## Хостинг

GitHub Pages, репозиторий `github.com/byalexei/byalexei.github.io`, ветка `main`.
Свой домен подключается в настройках репозитория: Settings → Pages → Custom domain.
